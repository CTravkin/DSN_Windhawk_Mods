# DSN Windhawk Mods

[English](README.md) · **Русский**

DSN Windhawk Mods — набор модов Windhawk для Windows. Каждый мод можно установить отдельно.

## Моды

| Мод | ID Windhawk | Назначение |
| --- | --- | --- |
| [Explorer Item Pins](Explorer_Item_Pins/README.ru.md) | `explorer-item-pins` | Закрепление файлов и подпапок внутри открытой папки Проводника |
| [Windows Border Switch](Windows_Border_Switch/README.ru.md) | `windows-border-switch` | Управление рамками окон, диалогов, меню «Пуск» и панели задач |
| [Refined Quick Settings and Sound](Refined_Quick_Settings_and_Sound/docs/README.ru.md) | `refined-quick-settings-and-sound` | Быстрые настройки и микшер Windows 11 с кнопками дисплея и ночного света |

[Лицензия MIT](LICENSE) распространяется на собственные моды DSN. Для Refined Quick Settings and Sound действует [GPL-3.0-only](Refined_Quick_Settings_and_Sound/LICENSE).
