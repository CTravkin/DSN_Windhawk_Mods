# DSN Windhawk Mods

[English](README.md) · **Русский**

DSN Windhawk Mods — набор модов Windhawk для Windows. Каждый мод можно установить отдельно.

## Функции

| Мод | ID Windhawk | Назначение |
| --- | --- | --- |
| [Explorer Item Pins](Explorer_Item_Pins/README.ru.md) | `explorer-item-pins` | Закрепление файлов и подпапок внутри открытой папки Проводника |
| [Windows Border Switch](Windows_Border_Switch/README.ru.md) | `windows-border-switch` | Управление рамками окон, диалогов, меню «Пуск» и панели задач |

### Ограничения Windows Border Switch

- Поддержка системных панелей зависит от сборки Windows и пакета Windows Web Experience Pack. Для некоторых панелей может потребоваться перезапуск Проводника или повторный вход в систему.
- Приложения, запущенные от имени администратора, могут сохранить рамки. Приложения с собственными рамками управляют их видом.
- Моды, меняющие ту же рамку или заголовок, могут перезаписывать изменения друг друга.
