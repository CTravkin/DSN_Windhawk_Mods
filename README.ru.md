# DSN Windhawk Mods

[English](README.md) · **Русский**

Моды Windhawk для Windows. Исходники, документация и тесты каждого мода находятся в его папке.

## Моды

| Мод | ID Windhawk | Назначение |
| --- | --- | --- |
| [Explorer Item Pins](Explorer_Item_Pins/README.ru.md) | `explorer-item-pins` | Закрепление файлов и подпапок внутри открытой папки Проводника. В разработке. |

У каждого мода своя версия. Для релизов на GitHub используются теги `<mod-id>-v<version>`. В каталог Windhawk подается самостоятельный файл мода `.wh.cpp`.
