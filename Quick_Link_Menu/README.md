# Quick Link Menu

**English** · [Русский](README.ru.md)

Quick Link Menu customizes the native Windows menu opened by **Win+X** or by
right-clicking the Start button. This prototype adds a submenu to the Terminal
row and uses the Windows labels for both Terminal commands.

## Features

- Click the Terminal row or press **Enter** to open Terminal. Click the arrow or
  press **Right** to open the submenu with the administrator command.
- Terminal, Settings, and File Explorer use Segoe Fluent Icons.
- The Terminal row uses the native hover state. In arrow-only mode, hovering
  over the arrow highlights just the arrow.

## Platforms

The prototype targets Windows 11 x64 and recognizes the English and Russian
Windows menu. It is incompatible with Windows 10 Win+X Restorer.

## Usage

In Windhawk, open **Open submenus on hover** in the mod settings. The default
mode opens the submenu immediately from anywhere on the row. The other modes
use the Windows delay or open immediately when hovering over the arrow.
