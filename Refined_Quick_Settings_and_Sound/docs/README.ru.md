# Refined Quick Settings and Sound

[English](../README.md)

Этот «vanilla+» мод для Windhawk перерабатывает панели «Быстрые настройки» и «Микшер громкости» Windows 11 и делает их пригодными для ежедневного использования. Он следует языку дизайна Windows 11, дорабатывая существующие функции и добавляя новые: тонкие ползунки, ровный шаг рядов при любом масштабе экрана и плавный переход рамки к странице «Звук».

Мод работает внутри панелей оболочки (ShellHost). Системный акрил, шрифты, темы и анимации сохраняются, а изменения оформления откатываются при выгрузке мода.

Эта версия основана на [оригинальном моде HeyOkay](https://github.com/HeyOkay/Refined-Quick-Settings-and-Sound).

## Возможности

**Быстрые настройки**

- Слева «Настройки» открывают параметры Windows. Кнопки параметров дисплея и ночного света включаются отдельно. Если кнопка уже есть в строке яркости, в верхнем ряду она не дублируется.
- Кнопка ночного света использует штатную плитку. Если плитка недоступна, открывается страница ночного света в параметрах Windows.
- «Яркость дисплея» по умолчанию работает в режиме «Авто». Используется штатный ползунок Windows, а при его отсутствии добавляется ползунок для мониторов с рабочим диапазоном DDC/CI. В режиме «Отключить» строка яркости скрывается.
- Можно выбрать от одной до четырех строк плиток быстрых настроек. По умолчанию две.

**Звук**

- Страница «Звуковой выход» теперь называется просто «Звук».
- Устройства вывода и ввода и поставщик пространственного звука выбираются из выпадающих списков.
- Ниже — переработанный микшер громкости приложений. Он сворачивается и запоминает последнее состояние.
- Колесо мыши работает на всех ползунках. Нажатие на значок приложения отключает и возвращает его звук, а нажатие на цифру громкости ставит 100.
- Приложения можно скрыть из микшера по имени (настройка мода).

**Панель задач**

- Нажатие на значок громкости сразу открывает «Звук».
- Системный анимированный значок громкости и значок Ethernet для проводной сети.

Идентификатор мода — `refined-quick-settings-and-sound`. Версия указана в `mod/sound-native.wh.cpp`.

## Совместимость

Windows 11 24H2 и новее с быстрыми настройками в ShellHost, x86-64. Оригинальный мод разрабатывался на сборке **26300**, преимущественно при масштабе **125%**. Обновления Windows могут менять внутренние элементы XAML и символы оболочки, от которых зависит мод. Добавленные подписи доступны на английском, русском, испанском, немецком, португальском (Бразилия) и упрощенном китайском. Для регулировки яркости DDC/CI должен быть включен на мониторе.

При первом открытии Sound в каждом процессе ShellHost микшер свёрнут; при последующих открытиях его состояние сохраняется. Отключите другие моды и правила оформления, меняющие те же элементы быстрых настроек, Sound или значка громкости.

Обнаружение панелей использует хуки COM-интерфейсов ControlCenter.dll и публичное дерево XAML; подключение XAML Diagnostics не создаётся. Совместимость с модами, меняющими те же элементы, требует живой проверки. Если панель была открыта при включении мода, закройте и откройте её; при необходимости перезапустите ShellHost.

## Установка из исходника

1. Установите [Windhawk](https://windhawk.net/).
2. Откройте [единый файл исходника](../mod/dist/refined-quick-settings-and-sound.wh.cpp).
3. Отключите оригинальный Refined Quick Settings and Sound. Создайте новый мод в Windhawk, замените шаблон исходником, скомпилируйте и включите мод.
4. Если панели не обновились, перезапустите ShellHost. Диагностические ошибки доступны в журнале Windhawk.

Готовая DLL не требуется. Быстрые настройки открываются через Win+A, Sound — через Win+Ctrl+V или значок громкости в трее.

## Сборка

Нужны Python 3 и установленный Windhawk (`build.ps1` использует `C:/Program Files/Windhawk/Compiler` и Engine 1.7.3; при другой установке поправьте пути).

```powershell
cd mod
.\build.ps1
```

`build.ps1` запускает `package.py`, который собирает единый исходник в `mod/dist/` из файлов в `mod/`. Проверка интерфейсов свойств запускается через `mod/test-model.ps1`. Для замера времени открытия панелей используется `tools/measure-panel-open.ps1`.
