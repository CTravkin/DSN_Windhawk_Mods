# Refined Quick Settings and Sound tools

| Tool | Purpose |
| --- | --- |
| [Build-Mod.ps1](Build-Mod.ps1) | Package the standalone source and build the x64 DLL |
| [package_mod.py](package_mod.py) | Assemble the standalone source from `Mod/Source/` |
| [Measure-PanelOpen.ps1](Measure-PanelOpen.ps1) | Measure native panel opening time |
| [Migrate-ModSettings.ps1](Migrate-ModSettings.ps1) | Convert a saved Windhawk settings JSON file to the grouped keys |

The converter prints JSON for the Windhawk editor. See [Moving saved DSN settings to the new groups](../README.md#moving-saved-dsn-settings-to-the-new-groups) for the backup and save steps.
