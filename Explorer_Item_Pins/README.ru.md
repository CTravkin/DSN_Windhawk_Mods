# Explorer Item Pins

[English](README.md) · **Русский** · [DSN Windhawk Mods](../README.ru.md)

Explorer Item Pins закрепляет выбранные файлы и подпапки вверху списка открытой папки Проводника Windows. У каждой папки свои закрепления.

## Функции

- **Два способа закрепить.** Через контекстное меню или кнопку с булавкой между «Поделиться» и «Удалить» на панели команд.
- **Сортировка и группировка.** Закрепленные объекты остаются наверху при любом направлении сортировки. При группировке они попадают в первую группу «Закрепленные». Внутри группы действует обычная сортировка Проводника.
- **Индикатор закрепления.** Булавка отображается в правом верхнем углу значка файла или папки. Она меняет размер вместе со значками и работает с миниатюрами, списком, таблицей, плитками и представлением «Содержимое».

## Платформы

Нужны [Windhawk](https://windhawk.net/) и Windows 11 x64 с вкладками в Проводнике. Проверено на Windows 11 26H2 (сборка `26300.9974`) с Windhawk 1.7.3. Совместимость с другими сборками Проводника зависит от доступности символов и совместимости внутренних интерфейсов.

## Обмен данными

Закрепления хранятся отдельно для каждой учетной записи Windows в `%LOCALAPPDATA%\Explorer Item Pins\pins.json`. При замене одноименного файла закрепление сохраняется. При переименовании в той же папке оно может сохраниться, если мод однозначно определит исходный файл по идентификатору. При копировании или переносе в другую папку закрепление за объектом не переносится.

## Эксплуатация

### Установка

1. В Windhawk выбрать «Создать новую модификацию».
2. Заменить содержимое `mod.wh.cpp` полным [исходником мода](Mod/explorer-item-pins.wh.cpp).
3. Нажать кнопку компиляции или `Ctrl+B` при открытой панели Windhawk. После компиляции выйти из редактора и убедиться, что **Explorer Item Pins** включен на главной странице Windhawk.

Для обновления открыть редактор установленного локального мода в Windhawk, заменить исходник и повторить компиляцию.

[Режим редактирования Windhawk](https://github.com/ramensoftware/windhawk/wiki/Editing-mode-guidelines)

### Использование

1. Для закрепления выделить файл или папку и выбрать «Закрепить в области объектов» в контекстном меню либо нажать кнопку с булавкой на панели команд.
2. Для открепления выделить объект и выбрать «Открепить в области объектов» либо нажать кнопку с перечеркнутой булавкой. Объект вернется на свое место в папке.

Все три параметра доступны в настройках мода в Windhawk. Они включены по умолчанию и отключаются независимо.

| Настройка | Что меняет |
| --- | --- |
| Команда контекстного меню | Закрепление и открепление из контекстного меню |
| Кнопка на панели команд | Закрепление и открепление с панели команд Проводника |
| Индикатор закрепленного объекта | Булавка на значках закрепленных файлов и папок |

### Проверка

Тесты запускаются из папки мода на Windows. Нужны PowerShell и компилятор из Windhawk 1.7.3.

```powershell
pwsh -NoProfile -File .\Tests\Test-PinStore.ps1
pwsh -NoProfile -File .\Tests\Test-ExplorerCommands.ps1
```

Тесты проверяют хранилище, одновременный доступ, операции закрепления, сортировку, группировку и отрисовку индикатора в нативном представлении Проводника, открытом в тестовом процессе.
