# Explorer Item Pins

[English](README.md) · **Русский**

Explorer Item Pins — разрабатываемый мод Windhawk для закрепления файлов и подпапок вверху списка открытой папки Проводника Windows.

## Статус

В текущей версии реализованы хранилище и сопоставление закреплений с объектами. Команды, порядок объектов и индикатор в Проводнике в разработке.

## Обмен данными

Закрепления хранятся отдельно для каждой учетной записи Windows в `%LOCALAPPDATA%\Explorer Item Pins\pins.json`. У каждой папки свой список. При замене одноименного файла закрепление сохраняется. Идентификатор файла помогает найти объект после однозначного переименования в той же папке. При копировании или переносе статус объекта в целевой папке определяется ее собственным списком.

## Эксплуатация

### Проверка

Для тестов хранилища нужны Windows, PowerShell и компилятор из Windhawk 1.7.3.

```powershell
pwsh -NoProfile -File .\tests\Test-PinStore.ps1
```

Тесты используют временную базу в `build\`. Они проверяют имена в Unicode, сохранение закреплений, операции с файлами на локальном томе, обработку некорректных данных и одновременную запись.
