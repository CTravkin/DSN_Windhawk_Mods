# Explorer Item Pins

[English](README.md) · **Русский** · [DSN Windhawk Mods](../README.ru.md)

Explorer Item Pins — разрабатываемый мод Windhawk для закрепления файлов и подпапок вверху списка открытой папки Проводника Windows.

## Функции

- Закрепление и открепление выбранного файла или папки через контекстное меню или панель команд.
- Закрепленные объекты остаются наверху при любом направлении сортировки. При группировке они попадают в отдельную верхнюю группу.
- Команду меню, кнопку панели и индикатор можно отключать независимо в Windhawk.

## Платформы

Текущая сборка рассчитана на Windows 11 26H2 x64 с системными DLL Проводника версии 10.0.26100.9949.

## Обмен данными

Закрепления хранятся отдельно для каждой учетной записи Windows в `%LOCALAPPDATA%\Explorer Item Pins\pins.json`. У каждой папки свой список. При замене одноименного файла закрепление сохраняется. Идентификатор файла помогает найти объект после однозначного переименования в той же папке. При копировании или переносе статус объекта в целевой папке определяется ее собственным списком.

## Эксплуатация

### Проверка

Запускай тесты из папки мода на Windows. Нужны PowerShell и компилятор из Windhawk 1.7.3.

```powershell
pwsh -NoProfile -File .\tests\Test-PinStore.ps1
pwsh -NoProfile -File .\tests\Test-ExplorerCommands.ps1
```

Тесты используют временные файлы в `build\`. Они проверяют хранилище, одновременный доступ, операции закрепления, сортировку, группировку и отрисовку индикатора в нативном представлении Проводника, открытом в тестовом процессе.
