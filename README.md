# DSN Windhawk Mods

**English** · [Русский](README.ru.md)

DSN Windhawk Mods is a collection of Windhawk mods for Windows. Each mod can be installed separately.

## Features

| Mod | Windhawk ID | Purpose |
| --- | --- | --- |
| [Explorer Item Pins](Explorer_Item_Pins/README.md) | `explorer-item-pins` | Pin files and folders within their parent folder in File Explorer |
| [Windows Border Switch](Windows_Border_Switch/README.md) | `windows-border-switch` | Control the borders of windows, dialogs, Start, and the taskbar |

### Windows Border Switch limitations

- Shell panel support depends on the Windows build and Windows Web Experience Pack. Some panels may require restarting Explorer or signing out and back in.
- Apps running as administrator may retain their borders. Apps that draw their own frames control their appearance.
- Mods that change the same border or title bar can override each other.
