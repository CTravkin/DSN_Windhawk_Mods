# DSN Windhawk Mods

**English** · [Русский](README.ru.md)

Windhawk mods for Windows. Each mod directory contains its source, documentation and tests.

## Mods

| Mod | Windhawk ID | Purpose |
| --- | --- | --- |
| [Explorer Item Pins](Explorer_Item_Pins/README.md) | `explorer-item-pins` | Pin files and folders within their parent folder in File Explorer. In development. |

Each mod has its own version. GitHub release tags use `<mod-id>-v<version>`. Windhawk catalog submissions use the mod's standalone `.wh.cpp` file.
